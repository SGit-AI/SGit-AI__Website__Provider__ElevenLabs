Ask this site

Two tiers in one pane. The default one needs no key, no model and no request to anybody: it matches your question against every page and every claim in the ledger and shows you what the site actually says. The second reads the answer aloud with your key.

Ask this site tier 1 · local matcher, no key voice off

Which pattern this is: pattern 0 with a ceiling — your own key, in your own browser, bounded only by your plan's quota. Defensible because it is yours and no key ships in this page; not a pattern to publish.

This is the tier-two version of this pane, and it is a trust decision rather than a feature. With a key it does one extra thing: it sends the answer text — never your question, never the page — to api.elevenlabs.io and plays the speech that comes back. The key is kept in this browser's localStorage, exactly as in the labs, and this site has no server to send it to. Everything above works with no key at all, which is the point of the tier.

Why it does not have a model behind it

Every other site would put a language model here, and this one deliberately does not. Three reasons, in the order they matter:

A model would be a second host. This site's central claim is that every page calls exactly one host, api.elevenlabs.io, in a request you start — and a build check fails the site if any other origin appears in it verified 7 Sep 2026. Adding a chat model would mean adding a provider, a key and an origin, and the claim would have to go. It is worth more than the feature.

A matcher cannot make things up. The pane returns the site's own sentences, with the state and date attached, and links to where each one lives. When it finds nothing it says so rather than generating a plausible paragraph — which on a site whose whole argument is no claim without a state is not a limitation, it is the requirement.

It is the honest tier-one artefact. The capability tier axis says a tier-one tool keeps no state and works for somebody with no key. This pane is that, and then it offers to become tier two — with the key panel written as a trust decision rather than a feature, which is the convention this estate already uses.

What the speech tier actually sends

If you open the key panel and turn speech on, one thing is sent, to one host: the answer text. Not your question, not the page you are on, not an identifier. The sentence spoken is a claim from the ledger — text that is already published on this site — and it goes to api.elevenlabs.io in the same shape as every lab here verified 8 Sep 2026.

It defaults to eleven_flash_v2_5 because an answer is not narration: half the price, and the meter under the panel shows what you have spent vendor docs 5 Sep 2026.

What it is not

It is not a support channel, it is not a model, and it is not an index of the vendor's documentation — asking it about an endpoint this site does not report on will correctly return nothing. For the vendor's API reference, the vendor's own documentation is better and fresher, which is the same rule the rest of this site obeys.
